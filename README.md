# Roga for Homebrew

The Homebrew tap for [Roga](https://roga.sh), a native Git client for reviewing what your agents wrote.

```bash
brew install --cask tmarkovski/roga/roga
```

Roga updates itself, so there's no need to upgrade it through Homebrew. The cask here is written by the release workflow in [tmarkovski/roga](https://github.com/tmarkovski/roga) each time a release is published.
